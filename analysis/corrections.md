# 2026-10-18 정정

더단백 초코 250mL의 당류는 0.8g이다. 사용자가 제공한 쿠팡 상세 영양표 이미지(C02)에서 확인했다. 처음에는 상품 요약만 확인하고 상세 이미지를 검토하지 않아 값을 누락했다. 자료 자체가 공개되지 않은 것이 아니라 조사 과정의 누락이다.

CSV·웹 발표·PowerPoint·발표 노트·분석 보고서에 반영했다. 단백질 20g과 열량 105kcal는 변경되지 않아 비용 및 열량 효율 순위는 그대로다. 현재 당류 값은 비교 제품 5개 중 4개이며, 마이밀의 현재 상세 라벨은 아직 미검증이다. 이를 회사의 미공개 정보라고 표현하지 않는다.

C02는 사용자 제공 이미지이고 독립적인 함량 시험이 아니다. 나머지 제품까지 상세 이미지를 모두 검증했다고 주장하지 않는다.
